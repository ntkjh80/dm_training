# 교재 그림 안내

아래 네 그림은 이 교재를 위해 새로 만든 한국어 설명 도식입니다. 원문 이미지의 복사본이나 제품 화면 캡처가 아닙니다. PNG는 Markdown 표시용, SVG는 문구와 배치를 수정할 수 있는 원본입니다.

| 그림 | PNG | 편집 가능한 원본 | 설명 |
| --- | --- | --- | --- |
| Decision 모델의 역할 | [보기](diagrams/decision-workflow.png) | [SVG](diagrams/decision-workflow.svg) | Unsloth 학습 경로의 입력·판정·처리 구분 |
| RAG 비교 | [보기](diagrams/rag-comparison.png) | [SVG](diagrams/rag-comparison.svg) | 기본 흐름과 판단 단계를 추가한 흐름 |
| 두 단계 판단 | [보기](diagrams/two-stage-gate.png) | [SVG](diagrams/two-stage-gate.svg) | 문서 관련성과 전체 답변 가능성의 차이 |
| PC별 실습 경로 | [보기](diagrams/pc-learning-paths.png) | [SVG](diagrams/pc-learning-paths.svg) | 모의 실행·로컬 추론·추가 학습 구분 |

RAG 개념의 출처는 [Avi Chawla의 X 게시물](https://x.com/_avichawla/status/2107767245917368751)과 [작성자의 상세 설명](https://blog.dailydoseofds.com/p/jev-for-rag-clearly-explained)입니다. 원본 동적 도식은 X 게시물에서 볼 수 있습니다. Unsloth 구조와 설치 경로는 [교재 출처 목록](../docs/14-sources.md)을 따릅니다.

고객 문의, 후보 문서, 확률, 기준값은 교육용 자체 예시입니다. 수치를 실제 모델 실행 결과나 성능 비교로 인용하지 않습니다. 두 번의 순차 판단은 남은 문서 집합을 확정하기 위한 이 교재의 구현 선택입니다.

SVG는 외부 이미지·웹 글꼴·스크립트를 불러오지 않습니다. 텍스트를 편집할 수 있도록 유지했으므로 표시 환경에 따라 글꼴이 달라질 수 있습니다. PNG에는 제작 시의 한글 글꼴 모양이 포함되어 있습니다.
