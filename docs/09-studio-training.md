# 09. 화면으로 나만의 모델 학습하기

1. Train 탭에서 unsloth/Qwen3.5-0.8B처럼 작은 기반 모델을 선택합니다. 앱에 해당 이름이 없으면 공식 모델 검색에서 확인합니다.
2. Train as를 Decision model로 설정합니다. 이 항목이 보이지 않으면 앱을 업데이트하고 모델 종류를 확인합니다.
3. practice/data/train.jsonl을 업로드합니다. state, questions, gold가 올바르게 읽혔는지 미리보기를 확인합니다. 보정 자료를 별도로 지정할 수 있으면 calibration.jsonl을 연결하고, 그렇지 않으면 앱의 holdout 분리를 사용합니다.
4. 아래의 교육용 설정으로 시작합니다. Start Training 전에 데이터가 건너뛰어졌다는 경고가 있으면 정답 키와 질문 형식을 고칩니다.
5. 먼저 짧게 실행해 메모리와 저장 동작을 확인하고, 다음 실행에서 전체 절차를 진행합니다. 학습 전후 지표와 처리 시간을 기록합니다.
6. 학습이 끝나면 실행 이름과 저장 경로를 적어 두고, 지원되는 경우 Use in Decision API에서 방금 만든 모델을 선택합니다. 새 입력으로 확인합니다.

근거: [1. 원문 학습 안내](https://unsloth.ai/docs/basics/train-your-own-decision-model-with-unsloth)

| 설정 | 교육용 시작값 | 의미 |
| --- | --- | --- |
| 4비트 LoRA | 사용 | 가중치 메모리를 줄임 |
| LoRA rank와 alpha | 각각 16 | 추가 가중치의 크기와 배율 |
| Learning rate | 2e-4 | 한 번에 조정하는 정도 |
| Batch와 accumulation | 1과 8 | 한 번에 1건씩 8번 누적 |
| 입력 길이 | 1024 | 원문과 질문을 합한 공간 |
| 정식 체험 | 2 epochs | 학습 자료를 두 번 순회 |
| 작동 점검 | 5 steps | 품질 평가용 학습량이 아님 |

작은 예제에 자동 holdout을 적용하면 보정 표본이 몇 건에 불과할 수 있습니다. 이때 보정 지표는 데모로만 읽으세요. 명시적인 24·12·12 분리와 최종 시험을 그대로 실행하려면 다음 장의 코드를 사용합니다.

메모리가 부족하면 batch를 줄이고 accumulation을 늘립니다. 이미 batch가 1이면 입력 길이를 줄이거나 더 작은 모델로 바꿉니다. 길이를 줄일 때 원문의 중요한 뒷부분이 사라지지 않는지도 확인합니다.
